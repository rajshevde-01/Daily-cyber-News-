# 🚨 "City-Forum" data-theft attacks target Salesforce, ServiceNow portals
**Source**: BleepingComputer
**Link**: https://www.bleepingcomputer.com/news/security/city-forum-data-theft-attacks-target-salesforce-servicenow-portals/
**Date**: 2026-08-13

## 📰 Summary of the Threat
The "City-Forum" data-theft campaign is an ongoing threat that targets Salesforce Experience Cloud and ServiceNow customer portals. The attackers utilize custom tools to exploit exposed data, which is accessible to anonymous users. This campaign highlights the importance of properly configuring access controls and ensuring that sensitive data is not exposed to unauthorized users. The technical mechanism of the vulnerability involves the exploitation of misconfigured portals, allowing attackers to steal sensitive data without requiring authentication.

The threat is particularly concerning because it targets widely used platforms, such as Salesforce and ServiceNow, which are commonly used by organizations to manage customer interactions and provide support. The fact that the attackers are using custom tools to exploit the vulnerability suggests a high level of sophistication and determination. The targets of the attack are likely organizations that use these platforms to manage sensitive customer data, such as financial information, personal identifiable information, or other confidential data.

The vulnerability exploited by the attackers is likely due to misconfiguration or inadequate access controls, which allows anonymous users to access sensitive data. This highlights the importance of regular security audits and configuration reviews to ensure that access controls are properly implemented and enforced. Organizations that use Salesforce Experience Cloud and ServiceNow customer portals should take immediate action to review their configurations and ensure that sensitive data is not exposed to unauthorized users.

## 🛠️ Actionable Defense & Mitigation Checklist
1. **Implement IP restrictions**: Configure IP restrictions on Salesforce Experience Cloud and ServiceNow customer portals to only allow access from trusted IP addresses. This can be done by using IP allowlisting or by implementing a VPN or proxy server to control access to the portals.
2. **Enable authentication and authorization**: Ensure that authentication and authorization are properly configured on the portals to prevent anonymous access to sensitive data. This can be done by implementing authentication mechanisms, such as username and password, or by using more advanced authentication methods, such as multi-factor authentication.
3. **Regularly review and audit configurations**: Regularly review and audit configurations of Salesforce Experience Cloud and ServiceNow customer portals to ensure that access controls are properly implemented and enforced. This can be done by using automated auditing tools or by performing manual reviews of the configurations.
4. **Use data encryption**: Use data encryption to protect sensitive data stored on the portals. This can be done by using encryption mechanisms, such as SSL/TLS, to encrypt data in transit, or by using encryption mechanisms, such as at-rest encryption, to encrypt data stored on the portals.
5. **Monitor for suspicious activity**: Monitor the portals for suspicious activity, such as unusual login attempts or access to sensitive data. This can be done by using logging and monitoring tools, such as SIEM systems, to detect and respond to potential security incidents.
